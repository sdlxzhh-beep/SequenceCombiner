碱基序列组合工具 1.2.1（Windows 64 位便携版）

一、启动
将 ZIP 完整解压到任意可写文件夹，双击 SequenceCombiner.exe。
不需要安装 Python、Excel 或其他第三方运行库。所有计算在本机进行。
目标系统：Windows 10 / 11，64 位 x64；不适用于 32 位 Windows。

二、操作
1. 程序初始提供 Group1、Group2。根据需要添加或删除组，新增组从 Group3 起递增编号，自动避开已有组名；删除组后不会重新使用已生成的编号。所有组名均可自行修改。
2. 在右侧粘贴这一组的碱基序列，每行一条。
   可从 Excel 中直接复制“碱基序列”这一列，不要同时复制氨基酸或编号列。
   也可以点击“导入 TXT / FASTA”。本版本不直接导入 XLSX。
3. 如果首个非空行是列名，勾选“首个非空行为表头”。
4. 需要某组的反向互补序列时，在该组中勾选“增加本组反向互补列”。
   每组独立设置，初始均不勾选。
5. 有更多序列组时点击“添加组”，最多支持 32 组。
   “上移”“下移”可以改变组顺序和输出列顺序。
6. 点击“计算 / 预览”核对每组有效序列数和总组合数。
7. 点击“TXT + XLSX”，选择一次保存位置，程序会自动生成两个文件。
   例如选择 result.txt，会同时生成 result_Excel.xlsx。
   在 Excel 中查看结果时直接打开配套 XLSX，每种组合一行，各组序列各占一列，无需手动分列。
   也可以点击“导出 XLSX”仅生成工作簿。
   等待导出完成提示后再打开文件。导出时可点击“取消导出”。

三、组合规则
每组各取一条序列，形成笛卡尔积。
例如三组分别有 2、3、4 条序列，共生成 2×3×4=24 种组合。
第一组变化最慢，最后一组变化最快，组内按输入顺序排列。
每组的原序列占一列，选择反向互补后会紧接着增加“组名_RC”列。
反向互补序列不会成为额外的候选序列，不会扩大组合总数。
原序列之间不会拼接成一条长序列。

四、输入处理
默认只接受 A、C、G、T，大小写均可，输出统一为大写。
移除序列中的空格、行首行尾空白及空行；接受 Windows CRLF、LF 和 CR 换行。
同一行内部若含制表符，按误粘贴多列处理并拒绝，不会将多个单元格拼接。请每次只粘贴一列序列。
默认组内去重，保留首次出现的序列；取消勾选后保留重复记录。
去重不会跨组进行。
FASTA 自动识别以 > 开头的记录，并拼接同一记录内的多行序列。
TXT 支持 UTF-8、UTF-8 BOM 和带 BOM 的 UTF-16LE / UTF-16BE。
遇到内嵌空字符、奇数长度 UTF-16 或无效编码时拒绝导入，保留当前输入内容。
单组文本导入上限 16 MB。
发现非法字符、空序列组或空 FASTA 记录时会提示，不会静默跳过。
组名不能仅为空格或包含制表符、换行等控制字符。所有输出列名（含 _RC）必须互不重复。
组名首尾的普通空格会被去除。

勾选“允许 IUPAC 简并碱基”后额外支持 R、Y、S、W、K、M、B、D、H、V、N。
对应互补关系：A↔T、C↔G、R↔Y、K↔M、B↔V、D↔H；S、W、N 自互补。
先互补再反转，结果按 5′→3′ 方向书写。
简并符号保留，不展开成 A/C/G/T 的额外组合。不接受 RNA 的 U。

五、导出说明
TXT：UTF-16LE BOM 编码，字段之间为真实制表符，每条组合以 Windows 换行符结束，第一行为表头。
TXT 是否自动分列仍取决于 Excel 的文本导入设置；配套 XLSX 已直接写入独立单元格，不依赖文本导入设置。
配套工作簿默认以“TXT 文件名_Excel.xlsx”命名；若已存在则自动增加编号，避免覆盖。
XLSX：标准 Excel 工作簿，首行冻结；使用未压缩 ZIP 封装，文件可能较大。
XLSX 单个工作表最多导出 1,048,575 种组合，另有一行表头。
超出行数或单条序列超过 32,767 字符时，程序会询问是否仅导出 TXT，不生成配套 XLSX。
本版本 XLSX 上限 4 GB，预计超限时也只能导出 TXT。
文件先写入 .partial 临时文件，完整关闭后才改为目标文件名。
正常取消或写入失败时删除本次临时文件，避免交付不完整工作簿。
保存名称须与导出格式匹配：TXT 使用 .txt，XLSX 使用 .xlsx。
TXT 成功但配套 XLSX 失败或被取消时，会明确提示仅 TXT 已保存。
若意外断电留下同名 .partial 文件，可选择新的保存文件名。

六、示例
examples 文件夹包含 Group1.txt 和 Group2.txt 通用合成测试序列，不含实验数据。
分别导入两组并保持表头选项关闭，组合数为 498×494=246,012。
为 Group2 勾选反向互补后，输出列为 Group1、Group2、Group2_RC。

七、验证范围
已验证：多组组合顺序、去重、非法输入、FASTA、多种反向互补和 XLSX 完整性。
v1.2.1 已通过 23 个针对性场景（包括四种文本编码、异常文件拒绝、列名冲突、取消/写入失败、已有文件保护、32 组/64 列和单元格长度上限）。
已通过 Windows 可执行文件的 API 模拟执行，逐行核对 246,012 条 TXT、配套 XLSX 和单独导出 XLSX 的结果。
当前构建环境不是 Windows，尚未进行真实 Windows 桌面界面的运行验收。

src 文件夹提供完整 C 源码、构建脚本和验证代码，供后续修改。
最终使用只需要 SequenceCombiner.exe，不需要 src 或 examples 文件夹。
